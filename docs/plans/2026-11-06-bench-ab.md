# Benchmark: bin/bench ab, a paired comparison of two nare commits

Issue #153, built on #154 (intervals) and #155 (provenance).

## Scope
In: `bin/bench ab --base REF --head REF`; each commit built as its own image;
reps interleaved per case; pooled Mantel-Haenszel and CMH; token and dollar
ratios paired by case; a power table in the README; unit tests on synthetic
counts; one small live proof.
Out: the full 120-rep run (a follow-up comment on the issue); any change to
`run`, `compare` or `bless`; gating a run on the A/B result.

## Assumptions
- Informative cases: blessed between 0.1 and 0.9 for the model's smoke
  baseline, plus any named with `--case`. With no baseline for the model, every
  case in the tier (the wider set costs more, and says so in the report).
- The A/B result reports and exits 0. It does not gate: the issue asks for the
  effect and its interval, not a verdict rule.
- The pass-rate effect is averaged over cases with equal weight; the odds ratio
  and CMH test are the stratified estimates and the test.
- Results live under `benchmarks/results/ab/<stamp>/`, outside `results/*.jsonl`.
