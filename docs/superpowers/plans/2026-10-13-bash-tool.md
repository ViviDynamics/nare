# Bash Tool: Honest Results, Nothing Left Running Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make nare's `bash` tool run real bash with pipefail, report signal exits as errors, report and record process groups a command leaves running, and have the TUI offer to kill them at turn end and on quit (issue ViviDynamics/nare#59).

**Architecture:** `run_bash` in `src/nare/tools.py` becomes a thin wrapper over a new `bash_outcome()` that returns a `BashOutcome` (text, whether it is an error, a process group left running). `dispatch()` turns that into a tool result and hands any left-running group to its caller through a keyword-only `left_running` callback, so nothing extra lands in a `tool_result` block. `step()` in `loop.py` records the group on a new `Session.process_groups` field (it has a default, so no contract bump). The TUI (`src/nare/tui/app.py`) reads that field: when a run settles and when a person quits, a `GroupsScreen` modal lists the live groups and offers **k**ill or **l**eave.

**Tech Stack:** Python 3.12, asyncio subprocesses, Textual 8.2, pytest with `asyncio_mode = "auto"`, ruff, mypy strict. CI is `bin/build`.

**Spec:** `docs/superpowers/specs/2026-10-08-bash-tool-design.md` on branch `origin/spec/tui-review` (not on main). Read it with `git fetch origin && git show origin/spec/tui-review:docs/superpowers/specs/2026-10-08-bash-tool-design.md`. Issue: `gh issue view 59 --repo ViviDynamics/nare`.

## Decisions the spec leaves open

These are settled here so every task agrees. A reviewer who disagrees should reject the task that owns the decision.

1. **"Turn end" means a TUI run settling on its own** (done, blocked or error), when the input box takes the next prompt. Not after each model step (a modal mid-run would stall an agent that starts a server and then curls it), and not after an interrupt (the quit prompt or the next turn end catches those). Owner: Task 6.
2. **Leave is remembered.** A group a person leaves at a turn end is not offered again at later turn ends in the same TUI process. Quit asks about every live recorded group, left or not, because quitting is the last chance. Owner: Tasks 6 and 7.
3. **Kill is SIGKILL to the group**, as the existing timeout and cancel paths already do. Owner: Task 3.
4. **`(cmd)` is a label**: the command's first line, redacted with `nare.events.redact`, whitespace collapsed, cut to 60 characters with `...`. Redacted before the cut, so a cut through a key never leaves an unmatched stub. The same label goes in the tool result and the session record. Owner: Task 3.
5. **The pkill hint appears only on a signal exit** whose command mentions `pkill`, `killall` or `kill`. Owner: Task 2.
6. **The still-running probe settles for about 0.1 s** before it reports a group. Measured on this machine: right after `pkill -f TAG; echo x` killed its own shell, `os.killpg(pgid, 0)` still succeeded in about one run in four, because pkill was a zombie that init had not reaped. Owner: Task 4.
7. **dispatch reports a left-running group through a keyword-only callback**, not an extra key on the result dict. `AnthropicTransport.messages_from` sends `tool_result` blocks as they are, so an unknown key would reach the API. Owner: Task 4.
8. **nare never signals pgid 0, 1, a negative, a bool, a non-int, or its own process group** (`os.getpgrp()`). `killpg(0, ...)` is the caller's own group, and a session file is data. Owner: Task 3.
9. **Escape at a groups prompt means leave**, the answer that changes nothing, as Escape means deny in `ApprovalScreen`. Owner: Task 6.
10. **The description stays static**, as the spec words it, even on the rare host without bash. The fallback still runs. Owner: Task 1.

## Review Focus

1. **A command that kills its own shell, whose child exits a moment later** (`pkill -f TAG; echo x`): the result must not claim `[still running: ...]` for a zombie init has not reaped yet. Test: `test_a_self_kill_does_not_read_as_a_group_left_running` in Task 4.
2. **`producer | head` under pipefail** (`yes | head -1`): exits 141 because the producer took SIGPIPE. That is an ordinary exit code, not a kill: the text says `exit 141` and the result is not an error. Test: `test_pipefail_reports_a_closed_pipe_as_an_exit_not_a_kill` in Task 2.
3. **A session file with a junk or dangerous pgid** (0, 1, -5, `true`, `"123"`, `None`, nare's own group): no signal is ever sent and nothing raises. Test: `test_nare_never_signals_a_pgid_it_may_not` in Task 3.
4. **A multi-line command, or one holding a secret near the 60-character cut**: the label is the first line only, and no part of the secret survives. Test: `test_group_label_is_the_first_line_redacted_then_cut` in Task 3.
5. **Ctrl-Q while a groups prompt is already open** (the turn-end offer, or the quit prompt itself): exactly one quit prompt, never stacked screens. Tests: `test_ctrl_q_during_a_turn_end_offer_asks_once_about_quitting` and `test_ctrl_q_at_the_quit_prompt_does_not_stack_another` in Task 7.

```python
_KILLERS = re.compile(r"\b(?:pkill|killall|kill)\b")

SELF_KILL_HINT = (
    "pkill -f also matches the shell running this command; use a pattern "
    "like `nex[t]-server`, or kill by `$!`."
)


@dataclass(frozen=True)
class BashOutcome:
    """One bash call: the text the model reads, and whether it is an error."""

    text: str
    failed: bool = False


def _status(code: int) -> str:
    """`exit N`, or the signal that killed the shell.

    A negative return code is a signal. Printed as `exit -15` it read as an odd
    exit code, not as the shell being killed.
    """
    if code >= 0:
        return f"exit {code}"
    try:
        name = signal.Signals(-code).name
    except ValueError:
        return f"killed by signal {-code}"
    return f"killed by {name} (signal {-code})"


async def bash_outcome(
    command: str, timeout: int = 120, *, cwd: str | None = None
) -> BashOutcome:
    """Run a command in bash with pipefail (sh without bash), in its own
    process group, with no stdin.

    `subprocess.run(timeout=...)` kills the shell and nothing the shell started,
    so `make dev &` outlives the call and the run leaks a server. The group is
    what makes the timeout mean what it says, and a cancel too.

    Async, not a worker thread: a thread in communicate() cannot be cancelled,
    so an interrupted command ran on and quitting the TUI waited for it.

    stdin is DEVNULL because nare's own stdin belongs to conductor: a command
    that reads would either eat conductor's pipe or block until the timeout.
    """
    proc = await asyncio.create_subprocess_exec(
        *_shell(command),
        stdout=subprocess.PIPE,
        stderr=subprocess.PIPE,
        stdin=subprocess.DEVNULL,
        start_new_session=True,
        cwd=cwd,
    )
    try:
        out, err = await asyncio.wait_for(proc.communicate(), timeout)
    except BaseException as exc:
        # ponytail: killpg reaches the group the shell leads. A grandchild that
        # calls setsid itself escapes it; a pid-tree walk is the upgrade, and
        # not before something actually escapes.
        with contextlib.suppress(ProcessLookupError):
            os.killpg(proc.pid, signal.SIGKILL)
        await proc.wait()
        if isinstance(exc, TimeoutError):
            # Raised, not returned: dispatch turns it into an is_error result,
            # so the model still sees the timeout and can adapt.
            raise subprocess.TimeoutExpired(command, timeout) from None
        raise
    output = (out + err).decode(errors="replace").strip()
    code = proc.returncode
    assert code is not None  # communicate() returns after the exit
    text = f"{_status(code)}\n{_truncate(output)}".rstrip()
    killed = code < 0
    if killed and _KILLERS.search(command):
        # The likeliest killer is the command itself: pkill -f matches the
        # shell whose argv holds the pattern.
        text += f"\n{SELF_KILL_HINT}"
    return BashOutcome(text, failed=killed)


async def run_bash(command: str, timeout: int = 120, *, cwd: str | None = None) -> str:
    """The text of bash_outcome(): what the model reads. dispatch() calls
    bash_outcome() itself, to learn whether the result is an error.
    """
    return (await bash_outcome(command, timeout, cwd=cwd)).text
```

```python
def _signalable(pgid: object) -> TypeGuard[int]:
    """A pgid nare may signal: an int above 1 that is not nare's own group.

    killpg(0) signals the caller's own group, and a pgid can come from a
    session file, which is data.
    """
    return (
        isinstance(pgid, int)
        and not isinstance(pgid, bool)
        and pgid > 1
        and pgid != os.getpgrp()
    )


def group_alive(pgid: object) -> bool:
    """Whether anything in the process group still exists.

    A zombie counts: kill(0) cannot tell one from a running process.
    """
    if not _signalable(pgid):
        return False
    try:
        os.killpg(pgid, 0)
    except ProcessLookupError:
        return False
    except PermissionError:
        return True  # it exists; it is just not ours to signal
    return True


def stop_group(pgid: object) -> bool:
    """SIGKILL a process group, as a timeout or a cancel does.

    False when nare may not signal that pgid or the kill was refused. A group
    that is already gone counts as stopped.
    """
    if not _signalable(pgid):
        return False
    try:
        os.killpg(pgid, signal.SIGKILL)
    except ProcessLookupError:
        return True
    except PermissionError:
        return False
    return True


def group_label(command: str) -> str:
    """One line that names a command, for `[still running: ...]` and the TUI.

    Redacted before it is cut: a cut through a key leaves a stub that no
    pattern matches.
    """
    first = (command.strip().splitlines() or [""])[0]
    line = " ".join(redact(first).split())
    return line if len(line) <= 60 else line[:57] + "..."
```

```python
    def _running(self, *, skip_left: bool) -> list[dict[str, Any]]:
        """Recorded process groups that are still alive, each pgid once.

        ponytail: a pgid recorded by an earlier process can since belong to an
        unrelated group, and kill(0) cannot tell. Recording a member's start
        time is the upgrade.
        """
        if self.session is None:
            return []
        seen: set[int] = set()
        live: list[dict[str, Any]] = []
        for group in self.session.process_groups:
            # Any: a session file is data, and group_alive() vets it below.
            pgid: Any = group.get("pgid") if isinstance(group, dict) else None
            # group_alive first: it refuses junk, which may not even hash.
            if not group_alive(pgid) or pgid in seen:
                continue
            if skip_left and pgid in self.left:
                continue
            seen.add(pgid)
            live.append(group)
        return live

    def _offer_groups(self) -> None:
        """At turn end: the live groups not already left, kill or leave."""
        groups = self._running(skip_left=True)
        if groups:
            self.push_screen(
                GroupsScreen(groups), lambda key: self._settle_groups(groups, key)
            )

    def _settle_groups(self, groups: list[dict[str, Any]], key: str | None) -> None:
        transcript = self.query_one(Transcript)
        for group in groups:

                self.left.add(group["pgid"])
                transcript.note(f"left running: {text}")
            elif stop_group(group["pgid"]):
                transcript.note(f"killed {text}")
            else:
                transcript.note(f"could not kill {text}", "yellow")
```
